# Вырезная (скелетная) анимация billboard-персонажа — практики (D-27, исследование ≤ 30 мин)

2026-10-08, агент D-27. Вопрос: как сделать бег героини из нарисованных частей на костях в Unity 6 URP, чтобы стопы не скользили и не было «бумажной куклы».

## 3 практики
1. **Klei (Don't Starve, Shank): символы + анимация отдельно.** Персонаж собирается в Flash из символов (рука, нога, тело); «build» — список символов с текстурами, «anim» — движение. Замена одежды и персонажа — подмена символов с теми же именами, движение переиспользуется ([GDC 2017, Agala/Bouthillier — «Doing 2D game animation the Klei way»](https://gamedeveloper.com/art/video-doing-2d-game-animation-the-klei-way); [формат anim/build/atlas](https://dontstarve.wiki.gg/wiki/How_to_extract_animations_from_the_game); [Klei forum о Shank](https://kleiforums.com/forums/topic/40914-whats-shank-art-technique/)). Для нас: одна походка на всех людей, у жителя — только свои части.
2. **ref2game (MIT) — «нейросеть рисует части, код двигает».** Лист частей (тело без конечностей, одна нога, одна рука, всё целиком); двухкостные конечности с IK; фаза шага от пройденного пути; стопа в опоре едет назад ровно со скоростью тела; таз от опорной ноги; руки в противофазе; дальняя конечность — тот же рисунок позади и темнее; круглые шапки суставов; проверки скриптом по трассе суставов (`references/animation.md` §1–5, §12, §14, §15).
3. **Unity 2D Animation (SpriteSkin + 2D IK, LimbSolver2D).** Штатный путь Unity для скелета на спрайтах; производительность растёт (Burst/кэш деформаций в 6.3), но рассчитан на `SpriteRenderer` и сортировку 2D ([обсуждение 6.3](https://discussions.unity.com/t/2d-animation-performance-improvements-in-unity-6-3-beta/1683239); [замер: стоимость — число SpriteSkin, костей и вершин](https://forum.unity.com/threads/performance-issues-with-skeletal-animation-2d-animation.1068707/)). Сравнения со «своим мешем» на телефоне никто не публиковал.

## Разрыв с текущим кадром
Сейчас бок — 12 видео-кадров Seedance (D-25): живая одежда, но кипение деталей (IoU 0,77) и ≈ 840 ₽ на весь набор. Вырезки в нашей манере (перо + акварель на billboard в 3D) не пробовал никто.

## Способы
- **А. Свой лёгкий риг на billboard** (выбран для пилота): части в одном атласе, один динамический меш на фигуру (порядок слоёв = порядок треугольников, один draw call), материал и оттенок карточки; походка — в ядре (`CutoutGait`, тесты на сервере, ADR-0008). Плюсы: тот же шейдер `Zelda/Toon` с отсечением альфы, глубина и свет как у карточки; тесты без Unity. Минус: свой код поз.
- **Б. Unity 2D Animation (SpriteSkin + LimbSolver2D)**: готовый редактор костей, но `SpriteRenderer` в 3D-мире с нашим шейдером и сортировкой по глубине — отдельная работа; походка всё равно своя (фаза от пути), IK-решатель — штатный. Отложено.
- **В. Мягкие кости по карте весов** (ref2game `softbones.py`) — для цельного рисунка зверей; для героини хуже (одежда тянется). Для D-28/зверей.
