# Разбор апреля: что брать в новую разработку

2026-10-07, три обзора только на чтение (логика, контент и данные, инструменты и арт) по `archive/2026-04/UnityProject` (до T-02 — `UnityProject/`). Правило (ADR-0007): **берём правила, числа, тексты и форматы; код не переносим** — пишем заново в ядре (`core/`, ADR-0008) или в новом проекте, сначала тесты. Ничего из апреля не проверялось на телефоне.

Пути ниже: `S/` = `Assets/Scripts/`, `D/` = `Assets/Data/`, `C/` = `Assets/Content/`. Числа брать из ассетов `D/`, а не из значений по умолчанию в коде.
