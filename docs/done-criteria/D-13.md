# D-13 · Бой в сцене — критерии (записаны до работы, 2026-10-08)

Цель: бой из основного управления (§6): тап — удар, замах врага читается, уворот отбеганием.
1. Кабан (логово в лесу) и ночные волки — спрайты по ядру (C-17, `g.Enemies`); не проходят сквозь дома (`Blocked`).
2. Тап по врагу в радиусе — удар героини (поза, звук-заглушка допустим), `[ZD:Combat] hit|miss`; вне радиуса — героиня поворачивается.
3. Замах врага читается ≥ 0,6 с: присед/отклонение назад + тряска + тень растёт; отбежала — `Dodged`, ловкость растёт.
4. Урон без цифр: враг вздрагивает/краснеет, оглушение — покачивание; героиня — оттенок раны (D-11).
5. Смерть врага → туша; тап без ножа — минимум один раз, с ножом — полный набор, туша исчезает; убитый кабан не возвращается после перезагрузки.
6. Нокаут героини от врага → враг уходит (ядро), нокаут-вид D-11.
7. PlayMode-тесты §7 D-13 зелёные; кадры: замах кабана, туша (`docs/demo/frames/D-13-*.png`).
