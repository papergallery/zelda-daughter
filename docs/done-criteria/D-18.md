# D-18 · Онбординг и реплики — критерии (записаны до работы, 2026-10-08)

1. Подсказки ядра (C-14): полупрозрачная рука — свайп (у нижнего края), тап (у ближайшей цели), лонг-пресс (у героини); исчезают после действия; не блокируют.
2. Реплики героини — облачко над ней рукописным шрифтом, гаснет через время из данных; не чаще пауз ядра.
3. Нигде нет HP-баров и цифр состояния; цифры — только в окнах сумки/торговли (количество, цены).
4. PlayMode-тесты §7 D-18 зелёные; кадры: подсказка свайпа на спавне, реплика (`docs/demo/frames/D-18-*.png`).
