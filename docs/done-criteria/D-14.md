# D-14 · Радиальное меню, инвентарь, крафт, еда, размещение — критерии (записаны до работы, 2026-10-08)

Цель: §1 (лонг-пресс на героине → радиальное меню), §7 (drag & drop крафт, размещение), §6 (еда на героиню).
1. Лонг-пресс на героине → меню «сумка / карта / блокнот» вокруг неё (карта — только если куплена); отпустила на секторе — окно.
2. Сумка: ячейки по `inventory.json`, иконки предметов (реестр; нет иконки — плашка), количество цифрой; бумага и тушь (`UiLook`).
3. Перетаскивание предмета на предмет → крафт ядра; реплика удачи/неудачи/«нужен станок».
4. За край окна — окно прячется, предмет на пальце: на героиню (еда/лечение), на NPC (поручение/торговля), на объект мира (костёр, факел), на землю (размещение; стена/вода — реплика «не сюда», предмет остаётся в сумке).
5. Костёр: дрова на землю + кремень на дрова → горит, светит, греет (отдых); `torch_unlit` к огню → `torch`.
6. Ходьба останавливается при открытом окне; тап мимо закрывает окно.
7. PlayMode-тесты §7 D-14 зелёные; кадры: меню, сумка, костёр ночью (`docs/demo/frames/D-14-*.png`).
