# D-10 · Регион в конфиге — критерии (записаны до работы, 2026-10-08)

Цель: стартовый регион §2 «Прототип» моделями (решения 5–6), собранный кодом из `scenes/region.json`.

## Проверяется (агент: сервер + ПК)
1. **Состав мест** (по `docs/concept/first-5-minutes.md` и §2): спавн у дороги (бревно) → дорога → поле с хижиной и крестьянином → лес/поляна (ягоды, палки, камни, кремень; логово кабана) → река с мостом (вода — замедление, переход — мост) → город: ворота/изгородь со стражником, площадь с фонтаном, лавка торговца, таверна (кровать внутри или у входа — тап по кровати), кузница с плавильней и наковальней, дом травницы, 2–3 дома жителей.
2. **Размер:** от спавна до дальнего края города — 2–3 мин ходьбы (PlayMode-замер, как T-09); точки интереса не реже чем каждые 10–15 с ходьбы по главной дороге (проверка на сервере по конфигу: расстояния между объектами с тегом `poi` вдоль пути ≤ 15 с × скорость шага).
3. **Сборка:** `SceneBuilder` дважды — один хеш; 0 ошибок и предупреждений; модели — из `ZeldaDaughter/Assets/Art/Models` (CC0, лицензии рядом), не из `ThirdParty`, кроме огня/звука.
4. **Коллизии:** героиня не проходит сквозь дома, ограды, деревья; проходит по мосту; в воде замедляется.
5. **Декор:** трава, кусты, камни россыпью по зонам детерминированно (сид в конфиге); не перекрывают дорогу и входы.
6. **Кадры** мест (спавн, поле, лес, мост, ворота, площадь) через `FrameCapture` — критик кадров: «читается, где дорога и куда идти», нет висящих в воздухе/утонувших объектов.
7. **Производительность** (Windows, редактор): треугольников в кадре и draw calls записаны в `docs/test-runs/` — база для D-19.

## Не входит
Вид (шейдер — D-08), спрайты (D-09), NPC и враги в движении (D-12, D-13).
