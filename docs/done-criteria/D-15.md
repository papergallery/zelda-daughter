# D-15 · Станки, сон, торговля, карта, блокнот — критерии (записаны до работы, 2026-10-08)

1. Кузница: тап по плавильне/наковальне → окно станка; положить материалы → жест удара → результат (руда → металл; металл + палка → меч; металл + короткая палка → нож); оружие только на наковальне.
2. Сон: тап по кровати в таверне → затемнение (глаза закрываются) → промотка часов → пробуждение; раны до порога; голод вырос.
3. Торговля: открыта только в часы лавки; две колонки (торговец / героиня) + стол сделки; бартер без монет; монеты — после урока; реакция торговца (Evaluate) до сделки; выкуп проданного.
4. Карта: покупается у торговца; контуры региона (запечены кодом сверху), открытые метки от разговоров; без «вы здесь».
5. Блокнот: записи героини от руки, новые сверху, без галочек.
6. Всё — без цифр состояния; цифры — только цены/количество.
7. PlayMode-тесты §7 D-15 зелёные; кадры: кузница, торговля, карта, блокнот, сон (`docs/demo/frames/D-15-*.png`).
