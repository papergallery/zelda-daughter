1. Масштаб: героиня ≈ 1/9 высоты кадра 1080×2340 (±15 %), камера по-прежнему изометрия.
2. Земля — 2–3 тона пятнами (декор/плоскости), дорога с рваной кромкой и камешками по краю.
3. Трава крупнее и реже, с цветами (жёлтые, лиловые); кроны — многошаровые модели; у спавна утром — туман над лугом (плоскости/частицы, по времени суток).
4. Дорога обходит фонтан (NPC не ходят сквозь него); на площади нет ели; другие объекты не перекрывают дорогу и входы.
