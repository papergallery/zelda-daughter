# D-24 · Героиня в манере жителей — критерии (записаны до работы, 2026-10-08)

1. **Манера как у жителей D-09:** голова ≈ 1/5–1/5,5 роста (как у ткачихи/молочницы), кисти и кеды крупнее, лицо упрощённое «книжное» (глаза-точки/штрих, без фотореалистичной светотени), линия пера и акварель той же плотности. Замер пропорций — на листе (px головы / px роста), рядом с 3 жителями.
2. Узнаваема: белая футболка, подвёрнутые джинсы, зелёный рюкзак, светлые кеды, тёмные волнистые волосы до плеч; взрослая молодая женщина, не ребёнок (рост 1,65 м по паспорту).
3. Полный набор D-09: стоит + 2 кадра шага × 3 ракурса, позы `attack`×2, `pickup`, `hurt`, `eat`, `down`; общий холст и pivot, PPU 320 (`tools/art/sprite_build.py`), реестр без изменений формата.
4. Сравнение: `docs/demo/sprites/D-24-lineup.png` — старая героиня, новая, 3 жителя в ряд; 2–3 варианта перед выбором; выбор и причина — в `docs/demo/decisions.md`; критик кадров по листу и по кадру из игры — ГОДИТСЯ.
5. Кадр из игры (`docs/demo/frames/D-24-*.png`): героиня рядом с жителем на площади; PlayMode `D11HeroViewTests` зелёные.
