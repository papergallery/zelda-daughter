# D-16 · Стихии и ночь в сцене — критерии (записаны до работы, 2026-10-08)

1. Дождь (по ядру): капли/штрихи, земля темнее (мокрая), грязь в зонах замедляет; мокрая трава не горит.
2. Огонь по сухой траве: факел/костёр поджигает клетку → огонь растёт по ветру → гарь; героиня обжигается в огне (реплика).
3. Ночь: волки появляются в зонах (не ближе порога к героине, не в свете костра), уходят утром; свет костра и факела (в сумке) освещает вокруг.
4. Производительность: огней одновременно ≤ 12, гарь — инстансингом.
5. PlayMode-тесты §7 D-16 зелёные; кадры: дождь, пожар травы, ночь с костром и волком (`docs/demo/frames/D-16-*.png`).
