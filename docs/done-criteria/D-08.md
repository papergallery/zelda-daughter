# D-08 · Вид мира — критерии (записаны до работы, 2026-10-08)

Цель: стилизованное 3D выглядит как «книжная иллюстрация — перо + акварель», палитра приглушённая тёплая (ADR-0001, решение 5).

## Проверяется (агент + критик кадров)
1. **Контур «пером»:** тёмная линия по силуэтам и изломам моделей, толщина постоянна в пикселях экрана (не мерцает при движении камеры), цвет — тёплый тёмно-коричневый, не чёрный.
2. **Акварель:** заливка мягкими ступенями (не гладкий PBR-градиент), бумажная фактура видна, края цветовых пятен чуть «растекаются»; общий тон — тёплый приглушённый (насыщенность ниже стандартной Kenney).
3. **Свет:** утро/день/вечер/ночь — по `WorldClock.Daylight`; ночь — синий лунный, читается дорога и силуэты; тёплые источники (костёр, факел, окна таверны) — светят.
4. **Персонаж-спрайт** (D-09; до него — пробный спрайт) вписывается: тот же контур/тон, не «наклейка».
5. **Кадры-эталоны:** F1 (дорога утром) и F1n (то же место ночью у костра) 1080×2340 через `FrameCapture` — критик кадров «ГОДИТСЯ»; рядом — кадр без эффекта для сравнения.
6. **Цена:** эффект — один Renderer Feature, параметры в одном ассете; на ПК 0 предупреждений; время кадра в редакторе записано (замер на телефоне — D-19).

## Не входит
Частицы огня/дождя (D-16), UI (D-14/D-15).
