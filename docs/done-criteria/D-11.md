# D-11 · Героиня в сцене — критерии (записаны до работы, 2026-10-08)

Цель: героиня — billboard-спрайт (ADR-0001), состояние читается без HUD (§1, §6).
1. Направление: движение к камере → вид «к камере», от камеры → «от камеры», вбок → «бок» (влево — зеркало); без дрожания на диагоналях (гистерезис).
2. Шаг: кадры шага сменяются по пройденному пути (не по времени); стоит — кадр не меняется; лёгкое подпрыгивание.
3. Действия кодом: удар (выпад/наклон к цели), подбор (присед), еда, разделка — видны ≥ 0,3 с.
4. Раны без цифр: перелом — хромота (неровный ритм шага, медленнее — из ядра), колотая/резаная — красноватый оттенок одежды и рука у бока (наклон/кадр), ожог — тёмный оттенок, отравление — зеленоватый; голод — нет визуала (только реплики).
5. Нокаут: героиня лежит, экран темнеет с 1–3 проблесками, встаёт; первые нокауты короткие (§6).
6. Спрайты D-09, если есть; иначе заглушка-силуэт с «носом»; спрайт пишет глубину (контур D-08 его видит), тень — пятно.
7. PlayMode-тесты из  §7 D-11 зелёные; кадры героини в 4 направлениях и в нокауте () — критик кадров «ГОДИТСЯ» (если спрайты D-09 готовы).
