# D-09 · Спрайты персонажей — критерии (записаны до работы, 2026-10-08)

Цель: billboard-спрайты героини, NPC и зверей в одной манере «перо + акварель», приглушённая тёплая палитра (ADR-0001), пригодные для сцены с изометрической камерой (наклон 35°, `scenes/*.json`).

## Проверяется (агент + критик кадров)
1. **Состав:** героиня (решение 1), крестьянин, стражник, торговец, кузнец, бармен, травница, 3 жителя, кабан, волк — у каждого ракурсы «к камере», «от камеры», «бок» (второй бок — зеркало кодом); у героини и зверей — минимум 2 кадра шага на ракурс; у NPC — минимум 1 кадр на ракурс.
2. **Согласованность:** на листе одного персонажа во всех ракурсах — тот же человек/зверь (одежда, цвета, причёска, пропорции); критик кадров — «ГОДИТСЯ» по листу каждого.
3. **Одна манера на всех:** контур тушью + акварельная заливка, тёплая приглушённая палитра; общий лист всех персонажей рядом у критика — «ГОДИТСЯ» (никто не выпадает фотореализмом, аниме, 3D-рендером).
4. **Ракурс сверху:** персонажи нарисованы с точки выше уровня глаз (видна макушка/плечи сверху), а не строго сбоку — допускается «чуть сверху».
5. **Техника:** PNG с прозрачным фоном, без ореолов (край проверен на тёмном и светлом фоне); один масштаб — пиксели на метр одинаковы для всех (рост из данных: героиня ≈ 1,65 м, кабан ≈ 0,9 м в холке, волк ≈ 0,8 м); pivot — между стоп; файлы в `ZeldaDaughter/Assets/Art/Sprites/<id>/` + `docs/demo/sprites/<id>-sheet.png` (лист для просмотра).
6. **Без** текста, логотипов, водяных знаков, оружия у тех, кому не положено.
7. **Лицензия:** модели и удаление фона — с лицензией, допускающей коммерческое использование (Klein 4B — Apache-2.0, BiRefNet — MIT); записано в `docs/demo/sprites/README.md` (модель, seed, промпт каждого листа — для повторения).

## Не входит
Анимация удара и состояний ран отдельными кадрами (D-11 — кодом поверх: наклон, оттенок, ритм шага); иконки (D-14/D-15).
