# D-26 · Ощущение боя и управления — критерии (записаны до работы, 2026-10-08)

Источник — `docs/demo/best-practices-feel.md`, раздел (в), пункты 1–8, 10–12, 15–16; числа — стартовые оттуда, менять можно с записью в `docs/demo/decisions.md`.
1. **Частота кадров:** `Application.targetFrameRate = 60` при запуске, Optimized Frame Pacing в Player Settings (сборщиком/скриптом), строка `[ZD:Perf] target=60` в журнале.
2. **Hit-stop** замораживанием поз/позиций billboard (не `Time.timeScale`): попадание 60–80 мс, удар по героине 100–120 мс, убийство 150–200 мс, промах 0; числа — в `data/`.
3. **Тряска камеры** по «травме» (травма² × max, шум, спад 0,3 с), max 0,08–0,12 м; настройка «без тряски».
4. **Вибрация** на Android (короткий эффект на попадание, сильнее на удар по героине; нет поддержки — тихо).
5. **Атака по касанию** на враге + буфер тапа 150 мс в перезарядке — ядро, тесты до кода.
6. **Уворот с запасом:** кабан windup 0,9 с, волк 0,7 с; удар врага засчитывается при дистанции ≤ range − 0,3 м — ядро/данные, тесты.
7. **Замах читается:** враг развёрнут к героине, кольцо тёмно-красное ≥ 1,5 диаметра, непрозрачность ≥ 0,6 к концу.
8. **Угроза сбоку:** ночью и в бою камера плавно отдаляется (≈ +20 % ortho за 0,5 с; героиня остаётся ≥ 1/11 высоты кадра), рычание волка с панорамой при < 15 м, светящиеся глаза у края света.
9. **Подсказки рукой без текста:** тап — тычок у цели, лонг-пресс — удержание с кольцом на героине, свайп — скольжение; текст — только после 20 с бездействия; подписи не поверх окон.
10. **Постоянные руны:** одно слово — одни руны у всех NPC (хеш от слова) — ядро, тест.
11. **Состояние двумя каналами:** голод (реплика + урчание + поза), рана (поза/хромота + дыхание), тяжёлое состояние — обесцвечивание мира до −25 % при тяжести ≥ 0,7.
12. **Бюджет сборки:** Build Report, лишнее из `ThirdParty` не в сборке, аудио Vorbis/mono; APK < 150 МБ (или причина в известных проблемах).
13. **Звук удара:** раздельно взмах / попадание / промах / убийство, попадание громче взмаха.
14. Тесты ядра и PlayMode зелёные (новые классы — `TestSaves.UseCleanFolder()`), сценарный проход D-19 зелёный; кадры/запись: hit-stop и тряска (последовательность кадров), глаза волка ночью, рука-подсказка у цели — `docs/demo/frames/D-26-*`.
