# D-21 · Вид по концепту — критерии (записаны до работы, 2026-10-08)

Ориентир — `docs/concept/world-b/f1.jpg`, `f1n.jpg`, `env-bridge.jpg`; README «Что взять в игру».
1. Контур — по силуэтам и рёбрам граней (по нормалям), тёмный оливково-сепийный (≈ `#1c2515`), 1–1,5 px при 1080×2340, не мерцает.
2. Тени — мягкие, тёплые сине-серо-умбровые, не чёрные; у мелкой травы и цветов теней нет.
3. Тон: середина дороги светлее, тени глубже — кадр не «весь в средних тонах»; зелень оливковая, без мятной/бирюзовой.
4. Брёвна, доски, деревянные части — коричневые, не оранжевые.
5. Ночь — глубокий синий без облачного шума; у костра видно пламя (Ian's Fire Pack), героиня и предметы рядом освещены огнём.
6. Кадры F1/F1n из игры рядом с концептом (`docs/demo/frames/D-21-compare-*.png`) — критик кадров: «ближе к концепту, ГОДИТСЯ для демо»; PlayMode — не хуже, чем было; 0 новых предупреждений.
