# D-25 · Плавная анимация — критерии (записаны до работы, 2026-10-08; пересмотрены по слову автора в тот же день)

Автор: «Плавные анимации надо не так калечно делать, а дорисовывать кадры между текущими». Процедурное движение (масштаб, сжатие, наклон кодом) — отклонено; плавность — **дорисованные промежуточные кадры** в манере D-09/D-24.
1. **Шаг 8 кадров на ракурс** у героини (front/side/back): кадр по пройденному пути (без скольжения стоп), дрожание опорной точки ≤ 2 px при 320 PPU, IoU силуэтов соседних кадров ≥ 0,8 (замер скриптом в `tools/art/`).
2. **Переходы кадрами:** поворот через промежуточные ракурсы (3/4), старт и стоп шага; удар 4–6 кадров (замах → удар → возврат), подбор, падение в нокаут несколькими кадрами, еда; стоя — 4–6 кадров дыхания/переминания.
3. **Способ дорисовки выбран замером:** пилот (видео-модель с первым и последним кадром; GPT Image «кадр посередине»; лист цикла одной генерацией) на одном ракурсе; выбор и цена — в `docs/demo/decisions.md`; критик кадров — ГОДИТСЯ.
4. **Код** берёт любое число кадров из реестра (цикл шага N, позы и переходы — списки), без аллокаций в кадре; старый набор (0,1,2) работает; тесты PlayMode на синтетических наборах зелёные; сценарный проход D-19 зелёный.
5. **Доказательство:** последовательность кадров из игры «до/после» (GIF или лист) — `docs/demo/frames/D-25-*`.
6. Жители и звери — той же техникой, если бюджет позволяет; иначе план и цена в решении.
