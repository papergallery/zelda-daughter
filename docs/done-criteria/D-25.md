# D-25 · Плавная анимация — критерии (записаны до работы, 2026-10-08)

1. **Слой движения кодом** (все billboard: героиня, жители, звери): дыхание стоя (масштаб по Y ≤ 2 %, период 2–3 с, фаза своя у каждого), покачивание и наклон по скорости, сжатие/растяжение 0,1–0,15 с на старте и остановке, разворот бок↔бок через сжатие по X ≤ 0,1 с, отдача на ударе; параметры — в одном месте (ScriptableObject/константы вида), без аллокаций в кадре (тест W0/D16 зелёный).
2. **Шаг 8 кадров на ракурс** у героини (после D-24): кадр выбирается по пройденному пути (без скольжения стоп), стоп не «плывёт» (дрожание опорной точки ≤ 2 px при 320 PPU), силуэт между соседними кадрами без скачков (IoU соседних кадров ≥ 0,8 у шага на месте, замер скриптом).
3. **Пилот двумя путями** (видео-модель Polza и лист 8 кадров одной генерацией) на одном ракурсе, сравнение по п. 2 + критик кадров; выбор и цена — в `docs/demo/decisions.md`; затем все ракурсы героини, при успехе — жители и звери (бюджет — в решении).
4. **Доказательство:** запись/последовательность кадров из игры (GIF или лист 8 кадров) «до/после» — `docs/demo/frames/D-25-*`; PlayMode-тесты вида зелёные; сценарный проход D-19 зелёный.
