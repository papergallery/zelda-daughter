# D-23 · Игровая петля демо — критерии (записаны до работы, 2026-10-08)

Источник — `docs/demo/known-issues.md` (раздел «Игровые»), `docs/demo/backlog.md`, `project-design.md`. Решения баланса принимает агент (ADR-0009) и пишет в `docs/demo/decisions.md`.
1. **Деньги и карта:** обычный игрок без подсказок может купить карту за ≈ 30–60 мин игры (письмо ткачихи + продажа добычи: шкуры, мясо, ягоды, клыки торговцу); расчёт — тест ядра «доход за типичный круг ≥ цены карты», числа — в `data/*.json`.
2. **Огонь против волков:** волк не подходит ближе радиуса костра/факела (из данных), при попадании в радиус — отступает; тест ядра + PlayMode.
3. **Факел догорает** за время из данных, затухание видно (свет слабеет), погасший — предмет «обгоревшая палка» или исчезает; тест ядра.
4. **Ночной волк:** ночью вне города появляется в 20–35 м от героини (не в 130 м), подходит и нападает, если нет огня; днём уходит; тест ядра (выбор точки) + PlayMode (волк дошёл и замахнулся).
5. **Описания предметов:** долгий тап по предмету в инвентаре показывает короткое описание (облачко, без HUD-цифр); тексты для всех предметов `data/items.json` — живым русским (content-writer).
6. **Поручение:** при сдаче — реплика «спасибо» NPC (руны/иконки по этапу языка) и награда видна.
7. **Реплики героини:** ≥ 3 новых ситуации (ночь/страх волка, дождь, первая покупка, сытость) из `data/`, без повторов подряд.
8. Тесты: ядро и PlayMode зелёные (`TestSaves.UseCleanFolder()` в SetUp новых классов); сценарный проход D-19 остаётся зелёным; кадры: волк у края света костра, облачко описания предмета.
