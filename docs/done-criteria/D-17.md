# D-17 · Звук — критерии (записаны до работы, 2026-10-08)

Цель: §9 — звук среды, без саундтрека; музыка только диегетическая.
1. Среда: лес (птицы, ветер), поле, река (вода у моста), город (голоса, кузница, телега — Cafofo), ночь (сверчки, тише); плавные переходы по зонам.
2. Шаги по поверхности под героиней: земля/дорога, трава, камень (площадь), дерево (мост — подобрать), вода.
3. Действия: удар, промах, попадание, замах зверя, огонь костра, подбор, крафт, сон, UI-бумага.
4. Бард/лютня в таверне вечером — слышно рядом с таверной, днём молчит.
5. Купленные звуки — только в `Assets/ThirdParty` (не в git); без них — тишина, сборка работает.
6. PlayMode-тесты §7 D-17 зелёные; запись `[ZD:Audio]` по шагам.
