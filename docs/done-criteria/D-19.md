# D-19 · Сборки и проход демо — критерии (записаны до работы, 2026-10-08)

1. **Сборки одной командой:** Windows release (мышь = палец, сцена `region` первая) и Android APK release (IL2CPP ARM64) — `BuildScript`, результат и размер — строкой `[ZD:Build]`; купленное из `Assets/ThirdParty` входит в сборку (на ПК), но не в git.
2. **Запуск:** Windows-плеер стартует без исключений (`Player.log`: `[ZD:Data]`, `[ZD:Save]`, без `Exception`/`Error`), 60 с без окна — без ошибок.
3. **Сценарный проход автотестом PlayMode** по региону: спавн → подсказка свайпа → палка → крестьянин (разговор, жест на город) → поляна (ягоды, кабан: замах, удар, туша) → мост → стражник → площадь → торговец (бартер, карта) → кузница (нож или меч) → таверна (сон) → ночь (костёр, факел, волк) → загрузка сохранения; каждая веха — строка `[ZD:*]` в журнале.
4. **Производительность** (Windows-плеер на ПК автора, 1080×2340 окно): fps и время кадра (среднее, 1 % худших), память, время запуска до управления — `docs/test-runs/…-demo-perf.md`; на телефоне — только если подключён (иначе — «не мерили»).
5. **Хвосты** из `docs/demo/backlog.md`, помеченные D-19, закрыты или перенесены в «известные проблемы» с причиной.
6. **Известные проблемы** — список в `docs/demo/known-issues.md` (что не так и почему), без скрытых.
7. Все тесты: ядро и PlayMode — зелёные (нестабильные — исправлены или помечены с причиной).
