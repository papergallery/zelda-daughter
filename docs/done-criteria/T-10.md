# T-10 · Игровая сессия в сером прологе — критерии (записаны до работы, 2026-10-08)

Цель: собрать ядро (С) в одну игру до выбора стиля. Всё видимое — **заглушка** (UGUI-текст, примитивы); вкус не оценивается — вид придёт в Р2 после GК. Правила решает ядро, Unity показывает.

## Проверяется в редакторе (агент, PlayMode через мост)
1. **Сессия:** в `prologue-grey` есть `GameSession` с `GameState` ядра; данные — тем же `DataSet.Load`; случайность — `System.Random` с сидом в Unity-слое (ядро получает броски).
2. **Время и свет:** часы ядра идут от `Time.deltaTime`; солнце (`Sun`) меняет наклон и яркость по `WorldClock.Daylight`; промотка на ночь даёт яркость солнца ≈ 0, на полдень — полную.
3. **Подсказка свайпа:** при первом запуске видна подсказка; после первого свайпа исчезает и не возвращается после перезапуска сессии (сохранение).
4. **Реплики:** когда ядро говорит «голоден» (голод выставлен ≥ порога), над героем появляется облачко с репликой из `data/remarks.json` и пишется `[ZD:Remark] <тема>: <текст>`; не чаще пауз из данных.
5. **Подбор:** тап по объекту с полем `item` (палка у дороги) — предмет в инвентаре ядра, объект пропадает, реплика подбора из `items.json`; после перезапуска объект не возвращается.
6. **Разговор:** тап по крестьянину — облачко над ним: тарабарщина ядра + иконки; появляются кнопки ответа-иконки; ответ иконкой ведёт по узлам или даёт «не понял» (по броску); в конце — жест на `town_gate` и `[ZD:Talk] peasant → town`; понимание языка выросло.
7. **Касания по кнопкам** ответа не двигают героя (UI перехватывает касание).
8. **Автосохранение:** при паузе/выходе и по таймеру из данных — файл слота (`SaveGame.WriteAtomic`), `[ZD:Save] saved`; новая сессия в той же сцене восстанавливает позицию героя, время, инвентарь, понимание языка, выполненные подсказки.

## Не входит
Вид облачков, иконок, подсказок (Р2-07, Р2-03 — после GК); телефон (T-07); бой, торговля, карта (этап В).
