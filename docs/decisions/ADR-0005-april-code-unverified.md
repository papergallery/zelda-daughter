# ADR-0005 · Апрельский код — сырьё, а не готовые этапы

- **Статус:** принято
- **Дата:** 2026-09-30
- **Кто решил:** агент по итогам аудита (ждёт подтверждения автора)

## Контекст
За 2026-04-08 агенты отметили 9 этапов `roadmap.md` (226 галочек из 235), следующие три дня ушли на розовые шейдеры, падения эмулятора и анимации. Проверки на реальной игре почти не было; результатов EditMode-тестов нигде нет.

## Решение
`roadmap.md` и апрельские документы тестирования — в `archive/2026-04/`. Статус систем — «написано, не проверено» (`docs/inventory-2026-04.md`). Система считается готовой только по новому плану: критерий до работы, доказательство с телефона, «годится» автора для видимого.

## Последствия
Код не выбрасываем: логика, SO-данные и тесты — основа для этапов после G2. Подключаем по одной системе.
