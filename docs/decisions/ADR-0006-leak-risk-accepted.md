# ADR-0006 · Утечка пароля Unity: риск принят, история вычищена

- **Статус:** принято
- **Дата:** 2026-10-07
- **Кто решил:** автор («менять не буду под свою ответственность»)

## Контекст
С 2026-04-08 логин и пароль Unity-аккаунта лежали в `.claude/settings.local.json` в публичном `papergallery/zelda-daughter` (R0-01). Проверка истории 2026-10-07: пароль был только в этом файле; в `INFRASTRUCTURE.md` — заглушка `PASSWORD`; форков у репозитория нет.

## Решение
Пароль автор не меняет. Агент переписывает историю без `.claude/settings.local.json` (`git filter-repo`) и делает `push --force`. Двоичные файлы истории в LFS не переводятся (R1-03): архив 142 МБ, а LFS на сервере без `git-lfs` в PATH даёт указатели вместо файлов и ломает `pre-push` (`thechest/docs/handbook/unity.md`).

## Последствия
Старые коммиты могут оставаться в кэшах GitHub и в чужих клонах — пароль из них не исчезает. Сторож правил (R0-05) не пропускает секреты в команды и коммиты. Репозиторий публичный: всё, что попадает в git, публикуется.
