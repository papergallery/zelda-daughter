# ADR-0003 · Unity только на ПК автора, эмулятор не используем

- **Статус:** принято
- **Дата:** 2026-09-30
- **Кто решил:** автор

## Контекст
В апреле Unity и Android-эмулятор работали на сервере (4 ядра, 7,7 ГБ ОЗУ, сейчас 13 ГБ свободно на диске) под Xvfb. SwiftShader падал от URP/Lit и Canvas, `adb input` до Unity не доходил, тесты шли на капсулах в 20+ отладочных сценах вместо игры. Unity и Android SDK с сервера удалены. В The Chest Unity работает на ПК автора через мост MCP (TensorLay) — проверено.

## Решение
Редактор, сборки и запуск игры — на ПК автора (`C:\dev\zelda`) через мост MCP на отдельном порту (R1-02). Проверка игры — на телефоне автора (adb с ПК, запись экрана). Сервер — код, данные, `dotnet test` ядра логики, документы, страницы для автора. Эмулятор и эмуляторные сцены не используются.

## Альтернативы
Вернуть Unity на сервер — не хватает памяти и диска, нет GPU, опыт апреля отрицательный.

## Последствия
Без включённого ПК видимое не проверить — работа идёт окнами. Мост и видеокарта общие с The Chest (busy-файлы). `EmuStageBuilder`, `CrashBisect*`, `smoke_test.sh`, `tests/` — в архив/удаление (R1-06).
