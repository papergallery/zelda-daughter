# ADR-0010 · Подход ref2game: рисованный мир по частям и вырезная анимация

- **Статус:** принято (пилоты D-27, D-28 решают масштаб)
- **Дата:** 2026-10-08
- **Кто решил:** автор («Я хочу побольше использовать https://www.youtube.com/watch?v=YQ01D9xGAnk в этом проекте»; «это дорого, я не готов на такие траты» про ≈ 1300 ₽ облачных роликов), агент — как именно

## Контекст
Ролик «2D-графика кодом» (Студия Игор) и открытый скилл ref2game (MIT, github.com/studioigor/ref2game) — разбор `docs/demo/ref2game-review.md`. Мир на 3D-моделях Kenney с акварельным фильтром не похож на концепты (`docs/concept/world-b/`); анимации кадрами из видео-модели дороги для бюджета автора (≈ 840 ₽ на всех).

## Решение
1. **Мир — рисованные куски:** деревья, камни, пни, брёвна, костёр, пропсы — рисованные billboard на прежних 3D-коллайдерах; земля — рисованные заливки в шейдере земли; дома/мост/фонтан — 3D, пока пилот не покажет иное. Свет, тени, туман, огонь, дым, вода, свечение — движком, в картинки не запекаются.
2. **Персонажи — вырезная (скелетная) анимация из сгенерированных частей**, как в ref2game и в самом Don't Starve: утверждённая «риг-поза» → части (тело без конечностей, рука, нога; дальняя конечность — та же часть позади и темнее; шапки суставов из текстуры конечности) → кости + IK в Unity, фаза шага от пройденного пути, таз от опорной ноги, руки в противофазе; для цельных (звери) — карта весов; анимация переиспользуется между похожими персонажами. На каждый ракурс (front/side/back) — свой набор частей. Видео-кадры (D-25, D-25c) — запасной путь и эталон сравнения.
3. **Процесс ref2game:** одна стиль-библия дословно в каждом промпте; генерация по одному куску; критики-скрипты анимации по координатам суставов (проскальзывание стопы, хромота, растяжение костей, рывки) + независимый критик кадров; страница превью.
4. **Порядок:** пилоты на одном месте — D-27 (героиня боком, вырезная анимация) и D-28 (уголок `f1` рисованными объектами, отдельная пилотная сцена) — затем масштаб победителя. ADR-0001 (billboard «перо + акварель» в 3D-мире, как Don't Starve) остаётся — меняется техника, не направление.
5. **Бюджет:** генерация частей — локально (FLUX.2 Klein на ПК) или GPT Image 1K (4 ₽) точечно в остатке Polza; облачных роликов не заказываем.

## Альтернативы
- Кадры из видео-модели для всех (≈ 840–1300 ₽) — отвергнуто бюджетом автора; остаётся эталоном и запасом.
- Процедурная анимация масштабом/сжатием — отвергнута автором раньше («калечно»); вырезная анимация на костях с IK — другое: части нарисованы, движутся суставы.
- Полный переход на 2D-слои ref2game (веб-движок) — нет: Unity, 3D-коллизии и свет остаются (ADR-0002, ADR-0008).

## Последствия
- Риск: швы суставов на акварели («бумажная кукла») — пилот D-27 меряет и показывает рядом с видео-кадрами.
