# ADR-0004 · Купленные ассеты: можно брать, в git не кладём

- **Статус:** принято
- **Дата:** 2026-09-30
- **Кто решил:** автор (разрешил использовать библиотеку Asset Store и докупать)

## Контекст
В прототипе — бесплатные CC0 (Kenney, KayKit). У автора на Asset Store 654 купленных пакета (`thechest/docs/asset-library.md`). EULA Asset Store не разрешает распространять исходники ассетов — а репозиторий был публичным.

## Решение
Купленные пакеты импортируются в `UnityProject/Assets/ThirdParty/` — эта папка в `.gitignore`. Список пакетов (название, издатель, версия, зачем) — `docs/asset-licenses.md`, чтобы проект воспроизводился на другой машине. Импорт на ПК автора через мост (`AssetStoreDownloadManager`, грабли — `thechest/docs/handbook/unity.md`). Свои и CC0 ассеты — в git, крупные бинарники через LFS (R1-03).

## Последствия
Сборку может сделать только машина с аккаунтом автора. Разбор, что брать, — R0-06.
