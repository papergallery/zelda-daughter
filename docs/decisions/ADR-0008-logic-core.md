# ADR-0008 · Правила игры — в чистом C#-ядре с тестами на сервере; Unity — представление

- **Статус:** принято
- **Дата:** 2026-10-07
- **Задача:** C-01 (`plan/stage-C-core.md`)
- **Кто решил:** агент по процессам The Chest (ждёт подтверждения автора, `docs/for-author.md`)

## Контекст
Unity есть только на ПК автора (ADR-0003); код Unity, написанный на сервере, не проверен до сборки на ПК. В The Chest вся симуляция — .NET-библиотека `sim/TheChest.Sim` (netstandard2.1, C# 9, asmdef `noEngineReferences`), Unity подключает её локальным пакетом `file:`, тесты идут `dotnet test` на сервере за секунды. В апреле правила игры жили в MonoBehaviour и проверялись EditMode-тестами, которые никто не запускал.

## Решение
1. Ядро — `core/ZeldaDaughter.Core/`: netstandard2.1, C# 9, без `UnityEngine`, asmdef `noEngineReferences: true`, `package.json` (`com.zeldadaughter.core`); Unity: `"com.zeldadaughter.core": "file:../../core/ZeldaDaughter.Core"`. Тесты — `core/ZeldaDaughter.Core.Tests` (xUnit), `core/ZeldaDaughter.sln`, запуск `tools/check.sh`.
2. В ядре — всё, что решает «что происходит»: распознавание жестов (тап / свайп / лонг-пресс по §1), намерение движения, время суток, состояние героя (раны, голод, усталость, нокаут), прогрессия через использование, инвентарь и скрытый вес, комбинации крафта, понимание языка, модель сохранения. Детерминированно: время и случайность приходят снаружи.
3. Числа баланса — в данных `data/*.json` рядом с ядром; ядро получает их объектами настроек (загрузка JSON — отдельным слоем, в Unity через `com.unity.nuget.newtonsoft-json`). ScriptableObject — только для того, что живёт лишь в Unity (ссылки на префабы, спрайты, звуки).
4. Unity-слой тонкий: читает ввод → передаёт в ядро → показывает результат; системы общаются событиями ядра.

## Альтернативы
- Логика в MonoBehaviour + EditMode-тесты (апрель) — проверка только на ПК, медленная обратная связь, тесты не запускались.
- ScriptableObject для всех чисел (прежнее правило `CLAUDE.md`) — не читаются из `dotnet test` без Unity.

## Последствия
- Правило `CLAUDE.md` «числовые параметры в SO» заменено: числа — в `data/`, SO — для ассетов Unity.
- `.meta` файлов пакета генерирует `tools/unity-meta.py` (детерминированный GUID, как в The Chest) — иначе на ПК они появляются неотслеженными.
- Ядро не должно тянуть `System.Text.Json` и прочее, чего нет в Unity (как в The Chest).
