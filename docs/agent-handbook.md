# Памятка агента: хост, ПК автора, общие ресурсы

Общее знание для любого агента (Claude Code, Codex). Перенесено из личной памяти Claude Code 2026-09-30. **Новое общее знание — сюда или в `handbook/`**, личная память — только для настроек инструмента. Порядок чтения: `CLAUDE.md` → `NEXT.md` → `plan/`.

## 1. Хост (сервер)
- 4 ядра, 7,7 ГБ ОЗУ (свободно ≈ 3 ГБ, своп в ходу), GPU нет, диск 118 ГБ — **свободно ≈ 13 ГБ** (2026-09-30). Здесь же The Chest (сайт, cron, агенты) и чужие сервисы.
- Unity, Android SDK, JDK, Xvfb на сервере **нет** и не ставим (ADR-0003). Лицензия Unity осталась в `~/.config/unity3d/`, не нужна.
- Тяжёлое (`dotnet build|test`) — только под общей с The Chest блокировкой: `flock -o /tmp/thechest-heavy.lock …` (`-o` обязательно, см. `thechest/docs/agent-handbook.md` §2 п. 3).
- `git-lfs` — `~/bin/git-lfs`, не в PATH; `git lfs install` на сервере не делать (ставит хуки, ломающие push).
- `gh` нет; GitHub API — `curl` с токеном из `~/.config/gh/hosts.yml` (токен в вывод не печатать).

## 2. ПК автора и общие с The Chest ресурсы
- ПК: RTX 4080 16 ГБ. Туннель TensorLay пробрасывает порты ПК на `127.0.0.1` сервера (подробно — `thechest/docs/handbook/access.md`). Жив ли — `curl -s -o /dev/null -w '%{http_code}' 127.0.0.1:6510/` (`000` — ПК выключен или туннель лежит).
- **Мост Unity MCP The Chest — порт 6510.** Для Zelda — отдельный порт (R1-02, ещё не настроен). Не трогать мост The Chest из этого проекта.
- **Busy-файлы общие:** видеокарта — `/tmp/thechest-gpu.busy` (генерация арта Zelda тоже её занимает), редактор Zelda — `/tmp/zelda-unity.busy`. Занять: `echo "<агент> <ID> $(date -Is)" > файл`; освободить: `: > файл`. Чужой busy — ждать.
- Генерация картинок — ComfyUI `8188` / SD Forge `7860` на ПК (поднимает автор). Пайплайн — `/var/www/html/Other/gpu-tunnel/character_pipeline/`.
- Редактор не закрывать и не убивать — с ним умирает мост. Мост молчит после сборки — почти всегда модальное окно.
- Клон на ПК — `C:\dev\zelda` (план, R1-01). Репозиторий — `github.com/papergallery/zelda-daughter`.

## 3. Грабли апреля, которые ещё актуальны
- **Library/Temp.** Не удалять `Library/` и `Temp/` целиком — полный переимпорт (в апреле 60+ мин на сервере). Застрявший лок — удалить только `Temp/UnityLockfile`, предварительно убедившись, что редактор не запущен.
- **Unity не видит `adb shell input tap/swipe`** (проверено на эмуляторе 2026-04): события не доходят. Для автоматического ввода — отладочный приёмник команд (`RemoteInputReceiver`, только за `#if ZD_DEBUG`) или `adb shell monkey`; на реальном телефоне ощущение управления проверяет автор.
- **Конвертация моделей через Blender** — долго и ненадёжно; сначала искать готовый формат (пожелание автора).
- **Материалы.** Апрельский `AndroidBuilder` выключал URP и перекрашивал материалы при каждой сборке — сборщик не должен менять настройки проекта (R1-06).
- Грабли Unity 6 / Asset Store / мост — общие с The Chest: `thechest/docs/handbook/unity.md`.

## 4. Как работать
- Вопросы автору — по одному, варианты принципиально разные, с рекомендацией (пожелание автора).
- Коммит после каждого законченного шага с ID задачи; после успешной сборки — обязательно.
- Секреты — никогда в репозиторий, allowlist, логи, коммиты.
