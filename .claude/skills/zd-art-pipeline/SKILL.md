# Арт: от промпта до кадра в репозитории

**Решение автора 2026-09-30:** кадры концепта генерирует автор во внешних сервисах; агент готовит промпты, принимает и проверяет картинки. Генерация на ПК (ComfyUI/Forge, видеокарта общая с The Chest — `/tmp/thechest-gpu.busy`) — только по слову автора.

## Промпты
- Источник — `docs/concept/first-5-minutes.md`: кадры F1, F1n, F2, F3, F4 × направления А/Б/В; общее (вертикаль 9:19,5, изометрия 35°/45°, герой ≈ 1/9 высоты), негатив, **[HERO]** до ответа автора о герое (`docs/for-author.md` п. 1).
- Новый кадр — по тому же шаблону: `[сцена] + [направление] + общее`.

## Приём картинок
1. Куда: `docs/concept/world-a|world-b|world-c/f1.png …` (направления мира), `art/sprites/<character>/…` (спрайты героя, K-03). В git — только PNG/JPG разумного размера; исходники и пачки вариантов — вне git.
2. Проверка: агент `frame-critic` (чеклист: формат, ракурс, масштаб героя, стиль ADR-0001, без HUD/текста/логотипов, читаемость, соответствие сценарию) → `ГОДИТСЯ` или `ПЕРЕДЕЛАТЬ` с правкой промпта.
3. Масштаб героя — замер высоты в пикселях по каждому кадру направления, в отчёт.
4. Прошедшее — на лист вкуса (навык `zd-taste-sheet`).

## Спрайты героя (K-03)
4 направления (перед, зад, бок — зеркалить, `flipX`), шаг ходьбы (кадры или части для cutout), «ранен». Импорт — переписанный `CharacterSpriteImporter` (Bilinear, ASTC, Sprite Atlas, кадры ходьбы — `docs/april-review.md` §3). Апрельский `character_pipeline` не согласует ракурсы — не годится как есть.
