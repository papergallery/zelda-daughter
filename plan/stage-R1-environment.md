### R1-02 · Мост для второго редактора
**Зачем.** Мост The Chest — `127.0.0.1:6510`; редактор Zelda не должен ломать вызовы The Chest.
**Находка 2026-10-07** (исходники `com.coplaydev.unity-mcp` v10.2.0, тот же пакет, что у The Chest): адрес сервера моста — в EditorPrefs `MCPForUnity.HttpUrl`, а EditorPrefs на Windows общие для всех проектов пользователя; настройки «на проект» в пакете нет. Если открыть второй редактор с пакетом, он подключится к тому же серверу на 6510 (HTTP-сервер держит несколько редакторов, `guides/multi-instance.md`). Вызов без выбранного инстанса тогда падает: «Multiple Unity instances are connected. Call set_active_instance…» (`Server/src/transport/plugin_hub.py`); `UNITY_MCP_DEFAULT_INSTANCE` действует только для stdio. Поэтому пакет в Zelda пока **не добавлен**.
**Варианты.** (1) Один сервер 6510 на два редактора: Zelda выбирает себя `set_active_instance`, The Chest — тоже (правка `tools/umcp.py` и памятки The Chest). (2) Редактор Zelda открыт только когда агенты The Chest мостом не пользуются (busy-файл `/tmp/thechest-unity.busy`). (3) Отдельный порт через подмену адреса в памяти процесса Zelda (рефлексия по `EditorConfigurationCache`) — хрупко. Выбор — за автором.
**Туннель.** Обычный `ssh -R` из PowerShell автора, как у The Chest (TensorLay автор не запускает).
**Готово, когда.** из сессии Zelda вызов консоли редактора возвращает ответ, мост The Chest при этом жив. **Кто.** автор+агент. **Объём.** S.

### R1-04 · Ядро логики без UnityEngine
**Зачем.** Формулы боя, ран, прогрессии, веса, крафта, языка проверяются на сервере за секунды, без редактора (как симуляция The Chest).
**Что сделать.** Вынести чистые классы в `UnityProject/Assets/Scripts/Core/Logic` (asmdef `noEngineReferences: true`) + `logic/ZeldaDaughter.Logic.Tests` (xUnit/NUnit, `dotnet test`, ссылается на те же исходники). Перенести туда подходящие из ~210 EditMode-тестов.
**Готово, когда.** `dotnet test` на сервере зелёный под `flock -o /tmp/thechest-heavy.lock`; те же исходники компилируются в Unity. **Кто.** агент. **Объём.** M.
