### R1-01 · Проект на ПК
**Что сделать.** Клон в `C:\dev\zelda` (рядом с `C:\dev\thechest`); открыть в той же версии Unity 6, что The Chest (`6000.3.24f1`); URP 14 → 17, Input System (сейчас `activeInputHandler: 0`, пакет стоит зря) — решить; убрать Cinemachine, если не нужен. Ошибки компиляции — списком в `docs/r1-01-migration.md`, не чинить наугад.
**Готово, когда.** проект открывается; список ошибок записан; `packages-lock.json` закоммичен.
**Кто.** автор (открыть, установить) + агент (через мост). **Объём.** M.

### R1-02 · Мост для второго редактора
**Зачем.** Мост The Chest — `127.0.0.1:6510`; два редактора на одном порту не живут.
**Что сделать.** Пакет unity-mcp в проекте Zelda, отдельный порт; проброс через TensorLay; `.mcp.json` на этот порт (сейчас он смотрит на удалённый `/tmp/unity-mcp`); правила занятости — `docs/agent-handbook.md` §2.
**Готово, когда.** из сессии Zelda вызов консоли редактора возвращает ответ, мост The Chest при этом жив. **Кто.** автор+агент. **Объём.** S.

### R1-04 · Ядро логики без UnityEngine
**Зачем.** Формулы боя, ран, прогрессии, веса, крафта, языка проверяются на сервере за секунды, без редактора (как симуляция The Chest).
**Что сделать.** Вынести чистые классы в `UnityProject/Assets/Scripts/Core/Logic` (asmdef `noEngineReferences: true`) + `logic/ZeldaDaughter.Logic.Tests` (xUnit/NUnit, `dotnet test`, ссылается на те же исходники). Перенести туда подходящие из ~210 EditMode-тестов.
**Готово, когда.** `dotnet test` на сервере зелёный под `flock -o /tmp/thechest-heavy.lock`; те же исходники компилируются в Unity. **Кто.** агент. **Объём.** M.

### R1-06 · Одна сцена из конфига
**Что сделать.** Вместо 17 сборщиков/«фиксеров» (`SceneBuilder`, `EmulatorSceneBuilder`, `EmuStageBuilder`, `CrashBisect*`, `MaterialFixer`…) — один `SceneFromConfig` + конфиг сцены; 25 отладочных сцен удалить; `RemoteInputReceiver`, `CrashDiagnostics`, `AwakeTracer`, `MeshBisector` — за `#if ZD_DEBUG`; `AndroidBuilder` не трогает рендер-пайплайн и материалы.
**Готово, когда.** в `Assets/Scenes/` — только сцены из конфигов; релизная сборка не содержит отладочных типов (проверка по списку типов в сборке). **Кто.** агент + мост. **Объём.** L.

### R1-07 · Сборка на телефон
**Что сделать.** `zd-build` навык: сборка APK через мост/`-executeMethod` на ПК, установка `adb` на телефон автора (по USB или Wi-Fi), запись экрана (`scrcpy --record`) → кадры на сервер.
**Готово, когда.** G1: видео с телефона — капсула идёт по свайпу, в logcat `[ZD:Move]`. **Кто.** автор+агент. **Объём.** M.
